## Задача по дизайну

Сайт за 10 секунд отвечает: где ближайшая точка, открыта ли она сейчас, как написать в WhatsApp. Главное действие — «Написать в WhatsApp», второе — «Маршрут в 2ГИС». Mobile-first: трафик идёт из Instagram и 2ГИС.

**Направление «Техпаспорт канистры»:** страница свёрстана как этикетка моторного масла — моноширинные подписи, строки характеристик, штрих-полосы. В херо — генеративный поток масла (flow field), который обтекает курсор. Заголовки наклонены, как курсив HELPER в логотипе.

**Тема «Отработка»:**
